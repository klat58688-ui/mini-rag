# 错误码速查（续）

## ERR_1005

ERR_1005 表示 SSL 证书校验失败。通常是系统时间漂移超过 5 分钟，或公司代理把证书劫持了。
排查时先 `date` 对时，再试试关掉代理直连。

## ERR_2088

ERR_2088 表示上游服务返回 502。负载过高触发熔断，可以先将实例摘流再重启。

## ERR_4102

ERR_4102 表示对象存储 bucket 不存在或区域配置错误。请确认 `.env` 里的 `S3_BUCKET` 与
`S3_REGION` 一致。

## ERR_5020

ERR_5020 表示消息队列消费滞后。看看消费组是不是卡在某个分区，必要时手动重置 offset。

## ERR_9001

ERR_9001 表示配置中心拉取超时。检查 `CONFIG_CENTER_ADDR` 是否指向了已下线的旧集群。
