# 退换货与运费

## 换货政策

### 换货有什么条件

签收后七天内、商品完好支持一次免费换货，邮费由平台承担。超出七天只能按退款流程评估。

### 换货后多久能发出

换货商品在收到退回件后 2 个工作日内发出，物流信息同步到订单详情页。

## 运费规则

### 退货运费由谁承担

无理由退货的运费由买家承担；商品质量问题导致的退货，运费由平台承担，先到付后报销。

### 部分退款是怎么算的

部分退款按实际退回商品金额折算，不影响订单中其他商品的售后权益。

## 异常场景

### 退款到账失败怎么办

退款失败通常是原支付账户已注销或银行卡状态异常，联系客服更换退款账户后 3 个工作日内重新发起。

### 拒收包裹后什么时候退款

拒收的包裹在退仓签收后 3 个工作日内触发退款，原路退回。
