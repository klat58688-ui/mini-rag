# 差旅报销细则

## 补贴类

### 交通补贴标准

市内交通按票据实报销，跨城高铁二等座、飞机经济舱各有上限，超出部分自理。

### 住宿发票有什么要求

住宿发票抬头需与公司全称一致，税率栏不得为空，否则财务会退回重开。

## 流程类

### 出差需要谁审批

出差前需在 OA 提交申请，依次经直属主管与财务审批后方可订票。

### 报销一般多久到账

报销单审批通过后 5 个工作日内打款到工资卡。

## 口径说明

### 一线城市名单

一线城市口径为北京、上海、广州、深圳，名单每年由财务复核一次。

### 超标住宿怎么处理

超出住宿上限的部分由个人承担，特殊情况可附说明申请主管特批。
